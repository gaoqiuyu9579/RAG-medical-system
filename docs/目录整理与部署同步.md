# 目录整理与 Docker 部署同步

日期：2026-11-12。

## 使用入口

在项目根目录打开 PowerShell，先打开 Docker Desktop，等待 Linux 引擎就绪：

```powershell
.\start.ps1                 # 正常部署，http://localhost:8080
.\start.ps1 -Demo           # 独立拟真演示，http://localhost:8081
.\start.ps1 status          # 正常部署状态
.\start.ps1 status -Demo    # 独立演示状态
```

两套服务均已完成构建与健康检查。正常部署继续使用原账号；演示初始账号为 `admin`，密码为 `Admin123456`。启动和停止的详细说明见 [README](../README.md) 与 [部署与启动](部署与启动.md)。

- 重建了最新 Vue 前端和 Flask 后端，包含流式问答、引用卡片、操作反馈、删除撤销、知识库进度和统计页。
