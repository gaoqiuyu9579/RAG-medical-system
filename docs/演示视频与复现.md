# 演示视频与复现

视频文件：`output/video/智慧医疗系统演示.mp4`。字幕文件：`output/video/智慧医疗系统演示.srt`。最终时长和逐章时间保存在 `output/video/video-metadata.json`，真实接口结果保存在 `output/video/demo-evidence.json`。

## 内容与制作方式

视频按项目介绍、架构、登录与统计、患者登记、电子病历、删除保护、资料导入、真实 RAG 问答、资料不足回答、优化策略、测试部署、团队与展望编排，共 12 个章节。台词源文件为 `docs/video_storyboard.json`。

核心功能画面来自 Playwright 对真实网页的录制，没有拦截接口或用固定回答替换实际模型。录屏后在片段末尾保留画面供讲解；技术介绍章节使用说明页。画面顶部标注隔离实例、合成资料和真实 AI 服务。配音使用 Windows 的 Microsoft Huihui Desktop 普通话合成语音，中文字幕同时烧录在画面中并提供独立 SRT。不是团队成员真人原声。

视频使用 H.264 / AAC，1920×1080，25 fps，时长需在 300 至 480 秒之间。脚本检查文件小于 100 MB，便于随 GitHub 仓库交付。源录屏、无压缩音频与临时片段在本机保留并排除 Git，最终 MP4、字幕、封面与去敏后的证据随仓库提交。

## 隔离演示账号

执行 `python scripts/demo_server.py` 后访问 `http://127.0.0.1:5502`：用户名 `reviewer`，密码 `ReviewDemo2026!`。该账号只用于本机隔离演示，新启动实例创建新数据目录，不改变已有数据库、管理员密码或 Docker 服务。

每次启动演示服务会在 `.test-artifacts/review-demo-随机标识` 下创建独立 SQLite / Chroma。AI 仍读取根目录 `.env` 中的实际服务配置；没有两类 AI 密钥不能重现真实向量化和问答。不要把该演示实例直接开放到公网。

## 重建方法（Windows PowerShell）

先按照 README 安装应用依赖并构建前端，再安装 `requirements-artifacts.txt`。本机需安装 Microsoft Edge、普通话 Huihui 语音和 Windows 中文字体：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-artifacts.txt
Set-Location frontend
npx playwright install ffmpeg
Set-Location ..
.\.venv\Scripts\python.exe scripts/demo_server.py
```

保留上述服务窗口，另开项目根目录 PowerShell 执行：

```powershell
node scripts/record_demo.mjs
.\scripts\synthesise_narration.ps1
.\.venv\Scripts\python.exe scripts/build_demo_video.py
.\.venv\Scripts\python.exe scripts/build_technical_pdf.py
```

先启动全新的隔离服务再完整录制，以免已有合成人员影响定位。停止隔离服务使用对应窗口 Ctrl+C，不停止已有 Docker 服务。重建脚本保留于仓库；Linux GitHub Actions 仅验证应用，不调用 Windows 语音和视频生成。
