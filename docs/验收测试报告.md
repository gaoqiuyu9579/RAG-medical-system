## 本次失败与修复

1. 首次浏览器运行 15 通过、1 失败。失败发生在移动端密码失效跳转场景，辅助函数在页面导航时使用 `page.evaluate`，执行环境被销毁。改为 Locator 可重试断言，完整重跑后 16 项全部通过。
2. 首次真实 RAG 校验已获得正确编号和来源，但清理临时 Chroma 目录遇到 Windows 文件占用，进程返回失败。改为子进程执行、结束后释放 SQLite 句柄，重新执行退出码为 0。
3. 演示录制前补装 Playwright 专用 FFmpeg 和开发环境缺失的 Waitress。第一次录制中成功提示断言与实际前端文案不同，修正录制脚本后重新录制；没有替换业务接口返回。
