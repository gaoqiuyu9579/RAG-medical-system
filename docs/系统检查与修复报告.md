前端 npm 扫描未发现已知漏洞。Python 本机扫描 122 项、实际 Docker 扫描 123 项，均只有 Chroma 0.5.23 仍存在 3 组公告及对应 PYSEC 编号：GHSA-2wm9-hf6c-p5cr、GHSA-36p7-vc44-83pf、GHSA-xph7-9rjv-w5fr。公告涉及 Chroma HTTP 服务端的多租户授权和远程模型执行，本项目只使用嵌入式本地集合，未启用这些运行方式；扫描结果没有列出修复版本，因此保留旧存储格式，不能称为依赖扫描零告警。

当前没有患者/病历编辑、分页、注册、细粒度病历权限、登录限流、审计日志或公网 HTTPS 配置。它们属于后续功能及正式部署完善范围。此次检查未进行公网渗透、长时间高并发压测、真实医生诊断质量评价或真实手机的 Wi-Fi/防火墙连接验证；未更改电脑防火墙。
