# 交互反馈改进与验收

更新日期：2026-11-12。按“让系统反馈更明显”的预审意见完善现有 Vue / Flask 项目。本次不生成或更新视频。

## 本次补齐

- 知识库上传进度移至共享状态。站内切换页面不会中断上传；返回问诊页重新打开上传弹窗，可继续查看当前阶段和处理结果。侧栏同步显示进度及上次导入失败提示。
- 重试失败问答时保留输入框中的下一条问题草稿，不重复添加原问题气泡。
- 收到 SSE 完成事件后立即恢复交互，不再等待 HTTP 连接关闭；断流仍显示失败气泡。
- 患者与病历保存失败时，弹窗内保留错误提示、已有输入和“重试保存”按钮；保存期间显示“保存中”。
- 编辑患者或病历时保持原有行位置，原行高亮 2.8 秒渐隐。

## 已实现

| 模块 | 可见效果与实现 |
| --- | --- |
| AI 问诊 | POST SSE 流，后端按模型增量返回，前端逐字渲染；检索与思考三点动画；发送时禁用输入和按钮；失败气泡与原问题重试，保留部分回答并标明未完成；重试保留新问题草稿 |

| 患者与病历 | 新增和编辑；保存 loading → 绿色对勾 → 恢复；失败时表单内显示错误并提供重试；保存后对应行高亮 2.8 秒渐隐，编辑保持原行位置 |
| 删除 | 二次确认包含患者姓名及红色警示；保留关联病历删除保护；已删除提示提供 30 秒撤销 |

| 加载 | 首屏加载提示、异步路由加载反馈、数据骨架屏与加载失败重试；页面 220ms 过渡 |

| 侧栏 | 入库文档数、知识片段数、就绪/解析/向量化状态；导航选中背景平滑移动 |
| 表单 | 提交时红边、抖动、行内错误和首个错误输入框聚焦；年龄整数范围校验 |

## 运行与演示

前端已构建。运行 `.\.venv\Scripts\python.exe scripts/demo_server.py` 后访问 `http://127.0.0.1:5502`，账号 `admin`，密码 `admin123456`。每次启动创建新 SQLite / Chroma 演示目录，不覆盖已有业务数据。AI 使用现有配置的真实外部客户端。

统计页入口为侧栏“数据统计分析”，提供患者年龄分布与近 7/30/90 天病历趋势。图表使用数据库汇总接口，包含零病历日期，不使用前端写死的图表数据。拟真患者仅用于独立演示实例，不覆盖已有业务数据。
