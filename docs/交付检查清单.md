## 文件验证

安装 `requirements-artifacts.txt` 后可在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe scripts/verify_deliverables.py
.\.venv\Scripts\python.exe scripts/verify_deliverables.py --online
```

脚本检查文件存在、PDF 页数及必需章节、MP4 实际尺寸和时长、音视频编码、团队信息、演示证据及受跟踪文件中的凭据模式；`--online` 另外匿名检查公开仓库与 PDF / MP4 / SRT 的发布大小。该扫描不能替代专业安全评估。
